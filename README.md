# 🎈 풍선 숫자 대전

한 화면에서 둘이 나란히 겨루는 아기자기한 숫자 퍼즐 게임입니다.
붙어 있는 숫자를 이어서 **합 10**을 만들어 지우고, 크게 지울수록 상대 판에 🎈 풍선을 올려 보냅니다.

## 바로 해보기

- **내 컴퓨터에서**: 리포지토리를 받은 뒤 `index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다. 설치할 것은 없습니다.
- **링크로 공유**: GitHub 리포지토리 → Settings → Pages → Branch를 이 브랜치(또는 main)의 `/ (root)`로 지정하면 `https://<아이디>.github.io/<리포지토리>/` 주소로 접속할 수 있습니다.

## 조작법

| | 🐰 토끼 (왼쪽) | 🦝 너구리 (오른쪽) |
|---|---|---|
| 이동 | W A S D | 방향키 |
| 고르기 / 취소 | F 또는 Space | Enter 또는 `/` |
| 게임패드 | 1번 패드 (십자키 + A) | 2번 패드 (십자키 + A) |

- `Esc` 또는 `P`: 일시정지
- `M`: 소리 켜기/끄기

## 규칙

1. 숫자 위에서 **고르기**를 누르면 체인이 시작됩니다.
2. 상하좌우로 움직이면 지나간 칸이 체인에 이어집니다. 방금 온 칸으로 되돌아가면 마지막 칸이 빠집니다.
3. 합이 **정확히 10**이 되면 그 칸들이 지워지고, 위의 칸이 떨어집니다. 10을 넘으면 체인이 취소됩니다.
4. 일정 시간마다 맨 아래에서 새 줄이 올라옵니다(판 아래 막대). 시간이 지날수록 빨라집니다.
5. 어느 열이든 **천장(빗금 줄)을 넘으면** 그 판은 패배입니다. 먼저 **2판**을 이기면 최종 승리입니다.

### 공격과 방어

| 한 번에 지운 칸 | 보내는 풍선 |
|---|---|
| 2칸 | 0 |
| 3칸 | 1 |
| 4칸 | 2 |
| 5칸 | 3 |
| 6칸 이상 | 4 |

- **콤보**: 3초 안에 또 지우면 콤보가 쌓이고, 콤보마다 풍선이 +1개 늘어납니다(최대 +3).
- **풍선 도착까지 3초**: 상대 판 위에 오고 있는 풍선이 보입니다. 그 사이에 내가 지우면 **내 공격이 먼저 오고 있는 풍선을 상쇄**합니다.
- **풍선 칸**은 고를 수 없습니다. 옆 칸을 지우면 터지면서 일반 숫자로 바뀝니다.
- **난이도**(쉬움/보통/어려움)는 줄이 올라오는 속도입니다. 플레이어마다 따로 정할 수 있어서 실력 차이를 맞추는 핸디캡으로 쓸 수 있습니다.

