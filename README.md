# 🎈 풍선 숫자 대전

한 화면에서 둘이 나란히 겨루는 아기자기한 숫자 퍼즐 게임입니다.
손가락으로 **네모를 그려** 안의 숫자 **합이 10**이 되면 지우고, 크게 지울수록 상대 판에 🎈 풍선을 올려 보냅니다.

## 각자 폰으로 하기 (온라인 대전)

### 1. 게임 주소 만들기 (처음 한 번만)
폰에서 접속하려면 게임이 인터넷 주소에 올라가 있어야 합니다. GitHub Pages로 무료로 올릴 수 있어요.

1. GitHub 리포지토리 → **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: 게임이 있는 브랜치 / **`/ (root)`** → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<리포지토리 이름>/` 주소가 생깁니다.

> 폰 홈 화면에 추가(사파리: 공유 → 홈 화면에 추가 / 크롬: ⋮ → 홈 화면에 추가)하면 앱처럼 열 수 있어요.

### 2. 연결하기
1. 한 명이 **📱 방 만들기**를 누르면 4자리 코드가 나옵니다.
2. 다른 한 명은 같은 주소로 들어와 **코드를 입력하고 참가**를 누릅니다. **🔗 링크 보내기**로 받은 링크를 열면 코드 입력 없이 바로 연결돼요.
3. 대기실에서 각자 난이도를 고르고, 둘 중 누구든 **시작!**을 누르면 같이 시작합니다.

### 조작 (터치)
- 손가락으로 **대각선으로 끌어 네모를 그리면** 그 안의 숫자가 모두 선택됩니다. 떨어져 있는 숫자도 한 번에 묶을 수 있어요.
- 네모 오른쪽 위에 합이 표시되고, **합이 10이면 초록색**이 됩니다. 그때 **손을 떼면 지워져요.** 10이 아니면 그냥 취소됩니다.
- 화면에는 내 판이 크게, 상대 판이 오른쪽에 작게 보입니다. 상대가 받을 풍선과 위험 상태도 실시간으로 보여요.
- 오른쪽 위 ⏸ 일시정지(둘 다 멈춤), 🔊 소리. 다른 앱으로 넘어가면 자동으로 둘 다 일시정지됩니다.

### 연결에 대해 알아둘 것
- 별도 서버 없이 **PeerJS 공개 중계 서버(0.peerjs.com)**로 서로를 찾은 뒤, 두 폰이 **직접(WebRTC)** 연결됩니다.
- **같은 와이파이일 필요는 없습니다.** 와이파이 + LTE, LTE + LTE 조합도 대부분 되지만, 통신사·공유기 환경에 따라 아예 연결이 안 되는 경우가 있을 수 있어요(중계용 TURN 서버가 없기 때문).
- **연결이 잠깐 끊기면** 둘 다 자동으로 멈추고 다시 연결을 시도합니다. 다시 연결되면 3초 카운트다운 후 이어서 하고, 끊긴 사이 보낸 공격도 전달돼요. 90초 동안 안 돌아오면 끊김으로 처리합니다.
- 상대가 다른 앱을 보는 중이면 "자리 비움"으로 표시하고 10분까지 기다립니다.
- 공개 중계 서버는 처음 서로를 찾을 때와 다시 연결할 때만 씁니다. 무료 서비스라 가끔 느리거나 멈출 수 있어요.

## 한 기기에서 둘이 하기
시작 화면의 **💻 한 기기에서 둘이 하기**를 누르세요. PC에서는 키보드를 나눠 쓰고, 태블릿에서는 각자 자기 판을 손가락으로 그으면 됩니다.

| | 🐰 토끼 (왼쪽) | 🦝 너구리 (오른쪽) |
|---|---|---|
| 이동 | W A S D | 방향키 |
| 고르기 / 취소 | F 또는 Space | Enter 또는 `/` |
| 게임패드 | 1번 패드 (십자키 + A) | 2번 패드 (십자키 + A) |

`Esc`/`P` 일시정지, `M` 소리. PC에서는 `index.html`을 더블클릭해도 실행됩니다(온라인 대전은 위 주소로 접속해야 함).

## 규칙

1. 네모를 그려 숫자를 고릅니다. 터치는 누른 채 끌기, 키보드는 **고르기 → 이동 → 고르기**입니다.
2. 네모 안의 숫자 합이 **정확히 10**이면 손을 뗄 때(키보드는 두 번째 고르기) 지워지고, 위의 칸이 떨어집니다.
3. 네모 안의 빈 칸과 🎈 풍선은 합에 들어가지 않습니다.
4. 일정 시간마다 맨 아래에서 새 줄이 올라옵니다(판 아래 막대). 시간이 지날수록 빨라집니다.
5. 어느 열이든 **천장(빗금 줄)을 넘으면** 그 판은 패배입니다. 먼저 **2판**을 이기면 최종 승리입니다.

### 공격과 방어

| 한 번에 지운 칸 | 보내는 풍선 |
|---|---|
| 2칸 (예: 3+7) | 0 |
| 3칸 | 1 |
| 4칸 | 2 |
| 5칸 | 3 |
| 6칸 이상 | 4 |

- **콤보**: 3초 안에 또 지우면 콤보가 쌓이고, 콤보마다 풍선이 +1개 늘어납니다(최대 +3).
- **풍선 도착까지 3초**: 상대 판 위에 오고 있는 풍선이 보입니다. 그 사이에 내가 지우면 **내 공격이 먼저 오고 있는 풍선을 상쇄**합니다.
- **풍선 칸**은 고를 수 없습니다. 옆 칸을 지우면 터지면서 일반 숫자로 바뀝니다.
- **난이도**(쉬움/보통/어려움)는 줄이 올라오는 속도입니다. 플레이어마다 따로 정할 수 있어서 실력 차이를 맞추는 핸디캡으로 쓸 수 있습니다.

## 폴더 구조

```
index.html          게임 화면
css/style.css       디자인
js/board.js         보드 규칙 (화면과 분리된 순수 로직)
js/net.js           두 기기 연결 (PeerJS)
js/game.js          진행, 입력(터치/키보드/패드), 그리기, 소리, 온라인 동기화
js/vendor/          PeerJS 1.5.4 (MIT 라이선스)
tests/board.test.js 규칙 테스트 (npm test)
docs/GAME_DESIGN.md 기획 문서와 앞으로 할 일
```

## 개발

```bash
npm test   # 규칙 테스트, Node 18 이상
```

온라인 대전을 공개 중계 서버 없이 시험하려면 로컬에 PeerJS 서버(`npm i peer`)를 띄우고
주소 뒤에 `?peerhost=127.0.0.1&peerport=9000&peerpath=/` 를 붙이면 됩니다.
